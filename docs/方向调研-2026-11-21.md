## 一、跨报告共识（三路以上独立指向同一机会 = 最高置信）

### 1. 程序化验证 oracle（最大公约数，可信度主线）
- 竞品路：XBOW 1060 报告 41% 全有效的核心是 **validators**——每类漏洞一个「LLM 检查+程序化断言」双轨验证（XSS 用 headless 浏览器断言 JS 真执行）。
- 学术路：DARPA AIxCC 冠军计分核心是 **PoV 可执行证明**；Google OSS-Fuzz AI 报告仅 1.3% 确认——假阳率是全场痛点；学术共识「渗透 agent 可信度不取决于模型，而取决于 harness（验证器/护栏/上下文工程）」。
- 我方已有：evidence_check 13 项人工可读验证 + 独立复现强制。**缺的正是「机验层」**：升级为每类漏洞一个可执行 validator 模板（XSS 探针断言执行/SSRF 带外命中/RCE 回显校验/SQLi 注入点闭环），PoV 脚本跑通才允许 critical/high 入报告。
- 落地：`validators/` 包按 vulnclass 注册断言器（复用 Playwright/http_request/带外监听）；evidence_check 评分为「人工项 + 机验项」两段。**工作量 M，收益：误报率核心下降+报告可信度质变。**

### 2. 经验沉淀（skill library / 武器库）
- 学术：Voyager 技能库范式（技能=可调用代码按语义检索）；EnIGMA 消融「演示轨迹 +6.2 最大增益因子」。
- 竞品：XBOW traces 回流强化；CAI 23 万会话轨迹数据集；NodeZero 确定性剧本重放。
- 我方已有：activity 全量记录 + 21 个静态方法论 skill + 靶场。**缺的正是「成功链路→可复用资产」**：任务收尾时把已验证攻击链提炼为参数化 playbook（YAML：前置条件/步骤/validator/适用指纹）入库，新任务按目标指纹检索注入。
- 落地：`playbooks/` 库 + planner 意图派发时检索注入 + 收尾提炼钩子。**工作量 M，长期复利。**

### 3. 可量化基准回归
- 学术：Cybench/NYU CTF/CAIBench/PentestEval 分阶段计分；「flag-oracle 可作弊→无预设 oracle 实靶」趋势。
- 竞品：PentestGPT 公示 XBOW suite 86.5%；CAIBench 元基准。
- 我方已有：本地靶场 + 同行对比 #12「CAIBench 式回归评测」候选（未实施）。
- 落地：双层基准——靶场层（ground-truth 漏洞清单+五指标 JSONL）+ 公开层（XBOW validation suite 抽样/CTF 抽样跑分公示）。每版跑一次防回归。**工作量 S-M。**

### 4. MCP server 化（产品层独有但杠杆最高）
- 业界先例：Orca Security 把平台能力暴露成 MCP server（Claude 直接调用）；Anthropic 官方确认此模式。
- 我们是 agent 平台+自部署单租户——**「自己是别人的工具」天然合适**：暴露 list_tasks/get_findings/run_recheck/agent_status/traffic_search 为 MCP server，用户在 Claude/Cursor 里直接指挥破军。
- 落地：Go MCP server（复用现有路由 handler 语义），MCP 预设反向挂载。**工作量 S-M，传播杠杆。**

## 三、与已有排期池的融合

**已有排期池（不变）**：OPSEC P0（身份 Profile+tls-client+工具参数守门+载荷卫生）→ #24a 多角色凭据池 → #23 crypto-relay → #25 流量 TTL → #22a 时间窗调度 → #16 任务级出口代理 → #14 情报源 → #48 导出导入。
**同行对比已列未实施**（标注归并）：#3 意图硬预算、#2 证据回验、#1 输出截断、#4 消毒、#8 状态机、#9 TDA 评分、#12 回归评测——全部归入本清单对应项，不再单列。

**融合建议（按批次）**：
- **v0.4.92（验证层冲刺）**：validator 库雏形（XSS/SSRF/RCE 三类先做）+ 输出截断+证据回验+意图硬预算——四个都是同行对比 P0 + 本轮共识 1 的交集，一次收口。
- **v0.4.93（能力域快赢）**：云/容器链（#11）+ sourcemap/扫密（#12）+ 浏览器探针（#14 雏形）——三个 S 级。
- **v0.4.94（经验层）**：playbook 武器库（#6）+ 变体分析意图族（#7）+ SimHash 分簇（#18）。
- **v0.4.95（产品层）**：MCP server 化（#21）+ SARIF/CI（#23）+ 复现命令标准件（#24）。
- **持续**：基准回归（#3 共识）作为每版门禁，靶场 ground-truth 先行。
- **远期**：AD 分析建议（#15）、exploit 索引（#16）、确定性剧本重放（#19）、TDA 评分（#8）、MCTS（#10）、黑板编排（#20）。

**明确不做（多路共识）**：fuzzing 基础设施自建、无线/物理、钓鱼自主投放、重型 RBAC、Tauri 桌面壳、Neo4j、LangGraph 换底座。
